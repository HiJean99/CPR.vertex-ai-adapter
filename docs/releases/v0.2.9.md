## What's changed

- Route both downstream `stream:false` and `stream:true` requests through Vertex `streamGenerateContent?alt=sse`.
- Return `TypedReply::with_stream` immediately after upstream response headers, moving model-generation reads out of CPR's 120-second `initial_reply` stage and into the resource-stream lifecycle.
- For downstream `stream:false`, collect the Vertex SSE response and emit one terminal `response.completed` `WirePayload::Json` event.
- For downstream `stream:true`, continue emitting OpenAI Responses SSE start, text-delta and completion events.
- Set `thinkingConfig.includeThoughts=true` when an explicit reasoning effort is supplied. Thought-only chunks are accepted as keepalives but filtered from downstream output.

## Compatibility and upgrade

- CPR: `>=3.38.2, <4.0.0` (RPC v7)
- Linux x86_64 package; statically linked with musl.
- No persistent-state or database migration is required.
- The model ID, upstream adapter ID, account group, Client Keys, project selection and Google ADC are unchanged. The existing upstream-adapter binding remains Provider `openai`, exact model `vertex/google/gemini-4-argon`, empty Account Group and Client Key scopes, and failure policy `reject`.
- No `quant` source or request parameter changes.
