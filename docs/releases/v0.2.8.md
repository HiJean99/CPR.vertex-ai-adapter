## What's changed

- Fix the static model capability declaration: Gemini 4 Argon now declares native `Reasoning` support, so CPR can route Responses requests containing `reasoning.effort`.
- Publish `low`, `medium` and `high` as supported reasoning effort levels, with `medium` as the default. These values match the adapter's existing Vertex `thinkingConfig.thinkingLevel` mapping.
- Preserve the single GA model `vertex/google/gemini-4-argon`, text-only Responses scope, non-streaming JSON and streaming SSE behavior.

## Compatibility and upgrade

- CPR: `>=3.38.2, <4.0.0`
- Linux x86_64 package; statically linked with musl.
- No persistent-state or database migration is required.
- The model ID, upstream adapter ID, account group, Client Keys and Google ADC are unchanged. The existing upstream-adapter binding remains Provider `openai`, exact model `vertex/google/gemini-4-argon`, empty Account Group and Client Key scopes, and failure policy `reject`.
